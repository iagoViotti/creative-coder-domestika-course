
# Javascript Creative Coder - Study Repository

This repository serves as a tracking tool for my progress in the Domestike Creative Coder. The course focuses on using HTML, CSS, and Javascript to create interactive and visually engaging web applications.

## Lessons Learned

- Fundamentals of HTML, CSS, and Javascript
- Techniques for using Javascript to create animations and interactive visual effects

## Run Locally

To run this code locally, you will need to have a code editor installed on your computer, such as Visual Studio Code or Sublime Text. You will also need to have a web browser installed.
1. Clone the repository to your local machine using: <br />

  ``` git clone https://github.com/iagoViotti/creative-coder-domestika-course```

2. Navigate to the project directory using the command line or terminal<br />

## Tech Stack

This project was built using the following tech stack:

- HTML
- CSS
- Javascript
